# AONet: An Anatomy-Aware Network for High-Fidelity 3D Retinal Neurovascular Parsing

## Overview

AONet is an anatomy-aware framework for 3D-to-2D retinal neurovascular segmentation from OCTA volumes. AdaAlign uses slice-wise spectral amplitude and an axial contiguity constraint to identify an informative retinal interval for each volume. Within this interval, HiF-Denoise extracts and adaptively refines high-frequency structural cues, while VoluSynergy combines slice-wise feature isolation with cross-slice contextual modeling. These features are progressively fused before a 2D segmentation head predicts capillaries, arteries, veins, and the foveal avascular zone. The design aims to reduce interference from non-retinal regions while retaining vascular continuity and fine-scale features during volumetric compression.

## Requirements

The released environment is based on:

- Python 3.10
- PyTorch 2.5.1
- CUDA 11.8
- NVIDIA GPU with CUDA support (e.g., NVIDIA RTX 4090 or higher recommended).

Install the dependencies with:

```bash
pip install -r requirements.txt
```

The versions in `requirements.txt` correspond to the environment used for this project. For a different CUDA or PyTorch setup, install compatible PyTorch, PyTorch Geometric, and compiled extension builds for your platform.

## Dataset

The code is organized for the **OCTA-500** dataset, which contains synchronized 3D OCT/OCTA volumes and annotations for retinal vascular structures. OCTA-500 comprises two fields of view:

| Subset | Subjects | Field of view | Volume resolution |
| --- | ---: | --- | --- |
| OCTA_3mm | 200 | 3 × 3 × 2 mm³ | 304 × 304 × 640 |
| OCTA_6mm | 300 | 6 × 6 × 2 mm³ | 400 × 400 × 640 |

## Configuration

Before running the code:

1. Set `dataroot` in `options/base_options.py` to the directory containing the dataset.
2. Set `modality_filename` and `label_filename` to the dataset and annotation identifiers used under `dataroot`.
3. Set the training and validation ranges through `train_ids` and `val_ids`.
4. Set `data_clip` in `train.py` and `test.py` to the JSON generated by AdaAlign.
5. For testing, set `bestmodelpath` in `test.py` to the trained checkpoint.

The default configuration uses a 320-slice input, five output classes, a batch size of 4, and 200 training epochs. Checkpoints and logs are saved under `log/<timestamp>/AONet/best_model/<modality>/`.

## Training

After completing the dataset and AdaAlign configuration, train AONet by running:

```bash
python train.py
```

## Testing and Visualization

Testing and visualization are both performed by running:

```bash
python test.py
```

The script loads the checkpoint specified by `bestmodelpath`, reports test mIoU, and saves color-coded segmentation predictions to:

```text
test_visuals/AONet_<modality>/
```

If the output directory already exists, a numbered directory is created automatically to avoid overwriting previous results.
